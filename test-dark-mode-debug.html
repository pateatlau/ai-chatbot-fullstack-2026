Common Issues & Solutions

Issue: Dark class not on <html>
Solution: ThemeProvider not rendering or not applying class. Check if ThemeProvider is mounted.
Issue: CSS variables not set
Solution: ThemeProvider not setting inline styles. Check ThemeProvider useEffect.
Issue: Variables set but colors still wrong
Solution: Tailwind not using CSS variables. Check tailwind.config.js colors section.
Issue: Works standalone but not in shell
Solution: Possible CSS scope/loading issue. Check if ui-components CSS loads in shell.
